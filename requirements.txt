# Conversor IGEA/CYMDIST → DGS — dependencias Python del proyecto.
#
# Un único fichero para todo lo necesario: motor de conversión, interfaz web, módulo
# VNR-GIS (vnr_etl) y herramientas de prueba. Antes estaban repartidas en cinco
# (requirements-dev.txt y tres vnr_requirements*.txt) y era fácil instalar solo una
# parte y encontrarse un ModuleNotFoundError a mitad de una conversión. Lo único que va
# aparte son los drivers opcionales de VNR-GIS, en requirements-drivers.txt, porque uno
# que no se descargue no debe impedir instalar el resto.
#
# El entorno es Python 3.12, ni más ni menos: es la versión contra la que está
# compilado powerfactory.pyd de PowerFactory 2024. Con cualquier otra no habla con
# DIgSILENT.
#
#   py -3.12 -m venv .venv
#   .venv\Scripts\activate
#   python -m pip install -r requirements.txt
#   python -m pip install -r requirements-drivers.txt   # opcional, solo VNR-GIS
#
# La web necesita además compilar el front una vez con Node:
#   cd frontend && npm install && npm run build
#
# Nota sobre PowerFactory: su API (powerfactory.pyd) NO se instala con pip. Viene con
# DIgSILENT y está atada a una versión concreta de CPython (PF 2024 → 3.12).
#
# Para ejecutar la suite completa con datos reales hacen falta además las tres
# variables de entorno de los TXT (y opcionalmente la base Access):
#
#   set IGEA_RED=referencia\RED_...txt
#   set IGEA_LOADS=referencia\CARGA_...txt
#   set IGEA_EQUIPMENT=referencia\BD_Equipo_...txt
#   set IGEA_MDB=D:\ruta\BaseDatos.mdb          (opcional, alternativa 2)
#
# Sin ellas las pruebas de integración hacen skip y solo corren las sintéticas.

# ── Paquete del proyecto (src/igea_dgs, src/vnr_etl + schemas/*.json) ──────────────
-e .

# ── Motor de conversión ──────────────────────────────────────────────────────────────

# Georreferenciación: GPS en terminales y diagrama IntGrf; reproyección en VNR-GIS.
# Sin esto solo se puede convertir con --no-geography.

# Alternativa 2 de entrada: base Access de CYMDIST (.mdb). También SQL Server/ODBC en

# de 64 bits, que se instala aparte con Microsoft Access Database Engine.
pyodbc>=5.0 ; sys_platform == "win32"

# Plantillas de cargas de SED en Excel (una hoja por alimentador) y export .xlsx.
openpyxl>=3.1

# Tablas de las exportaciones analíticas.

# Validación independiente del modelo: flujo de potencia y detección de islas con un
# motor distinto de PowerFactory, sin licencia y en segundos.
pandapower>=3.0

# La vista previa del mapa usa leafmap si está instalado (requirements-drivers.txt) y,
# si no, Leaflet por CDN: no hace falta para convertir.

# API FastAPI + front React compilado (frontend/dist), que sirve esta misma API.
