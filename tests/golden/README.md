# Casos dorados

Estos archivos son expectativas sintéticas preparadas independientemente del conversor. No demuestran aceptación de un alimentador real. Un caso real solo puede marcarse aprobado cuando contiene hashes SHA-256 de TXT/DGS, revisor, fecha, procedencia de la medición PowerFactory, KPIs y tolerancias fijadas antes de ejecutar la comparación.

Los tres casos ejercitan red balanceada, no balanceada y generación. `status=synthetic` impide confundirlos con evidencia real.
